🎓 NEXTLEAP PRODMAN MVP vs ACTUAL APP

Changes Made in this MVP

Highlighting all product changes & new features added in this prototype compared to the baseline Google Photos app (from user research & screenshots).

✨ Highlight MVP Changes Glow badges & spotlight markers in app
CHANGE 1 • PHOTOS FEED Inspect in App →
✨ AI Keyword Discovery Hero Card
✕ Actual Google Photos: Opens directly to photo feed & memories. Zero proactive discoverability on how to search naturally.
✓ Added in MVP: Prominent hero card with live animated ticker cycling sample memory queries with color-coded tags + 1-tap example pills.
📈 Impact: Solves 0-to-1 adoption by teaching natural memory recall before users get stuck.
CHANGE 2 • NAVIGATION Inspect in App →
🎯 Standalone Search FAB & Coachmark Tooltip
✕ Actual Google Photos: Search is buried in bottom nav tab or plain icon without affordance or guidance.
✓ Added in MVP: Elevated circular FAB with pulsing halo + contextual floating coachmark tooltip pointing to Search.
📈 Impact: Forms instant search habit for retrieval as primary user journey.
CHANGE 3 • SEARCH CORE Inspect in App →
🧠 4-Dimension Natural Recall Engine
✕ Actual Google Photos: Strict metadata/date matching or unguided freeform Gemini "Ask" box.
✓ Added in MVP: Natural cognitive parser mapping queries into Who (faces), What (occasions), When (timeline/season), Where (places).
📈 Research Stat: Users recall Who/What/Where 100% of the time, but exact dates 0% of the time.
CHANGE 4 • LIVE FEEDBACK Inspect in App →
📊 Live Coaching Hint & Findability Meter
✕ Actual Google Photos: Completely absent. If search yields 0 results, user gets no guidance why.
✓ Added in MVP: Dynamic strength meter (Weak → Excellent) + actionable coaching prompts as you type.
📈 Research Stat: Adding a rough timeline increases search success by 2.7×.
CHANGE 5 • RESULTS VIEW Inspect in App →
🏷️ Contextual 1-Tap Refinement & Clue Chips
✕ Actual Google Photos: Generic static filters (Documents, Screenshots) rather than query-specific narrowing.
✓ Added in MVP: Active clues shown as removable chips + dynamic refinement pills (+Ananya, +Wedding, +2026) mined from results.
📈 Impact: Narrows down large candidate photo sets to the target memory in 1 tap.
CHANGE 6 • PEOPLE & COLLECTIONS Inspect in App →
👥 Scoped Keyword Search in People
✕ Actual Google Photos: People albums only display static photo collections or unguided global search where queries return other people.
✓ Added in MVP: Scoped keyword search directly inside any person's photos with contextual face avatar pill, dedicated status banner, strict candidate pool (guarantees NO other faces appear), and 1-tap filter chips (All, Only [Name], Occasions, Places).
📈 Impact: Lets users instantly pinpoint specific memories with a loved one without other faces mixing in.
CHANGE 7 • ONBOARDING Inspect in App →
📖 Interactive 4-Clue Recall Modal Sheet
✕ Actual Google Photos: No onboarding for natural memory search.
✓ Added in MVP: Educational sheet breaking down Who/What/When/Where with clickable one-touch demo queries.
📈 Impact: Eliminates blank canvas anxiety for first-time searchers.
